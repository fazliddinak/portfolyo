## 🚀 How to Run the Website

### Option 1: Direct Browser Launch (Zero Installation)
Simply double-click `index.html` in your file explorer, or right-click and choose **Open with Google Chrome** (or Edge, Firefox, Brave).

### Option 2: VS Code Live Server
1. Open this folder in VS Code:
   ```bash
   code .
   ```
2. Right click `index.html` and click **"Open with Live Server"**.

---

## 🌐 Deploying to the Web

### Deploy to GitHub Pages:
1. Create a repository on your GitHub account (`https://github.com/fazliddinak/portfolio`).
2. Push this folder to the `main` branch.
3. Go to **Settings -> Pages -> Branch: main -> Save**.
4. Your portfolio will be live at `https://fazliddinak.github.io/portfolio`!

### Deploy to Vercel or Netlify:
- Simply drag and drop this entire project folder into the [Vercel](https://vercel.com) or [Netlify](https://netlify.com) dashboard. It deploys in 5 seconds with zero build configuration!
